# Polycrayons-Demo

POLYCRAYONS BAY HORIZON — 360° Luxury Virtual Tour & Masterplan

🔗 **Live Frontend URL**: [https://polycrayons-demo.vercel.app/](https://polycrayons-demo.vercel.app/)

An ultra-luxury 360° interactive virtual walkthrough and real estate masterplan application built with Three.js, Vanilla JavaScript, and Modern CSS.

## Features
- **Architectural 3D Entrance**: Double beveled grand doors with heraldic crests, ambient stardust embers, and dynamic walkthrough zoom-in.
- **360° Virtual Tour & Panoramas**: High-resolution day and night drone panoramas across tower elevations.
- **Interactive Hotspots & Radar Compass**: Real-time orientation and landmark discoveries.
- **Elevation Selector & Floor Plans**: Multi-tier tower navigation with unit inventories and inquiry management.
- **Lead Capture & Sales CRM Engine**: Inquiries with export functionality.

## Tech Stack
- Vite
- Three.js
- Vanilla JavaScript (ES Modules)
- Vanilla CSS Design System
- Express.js Backend

## Getting Started
```bash
# Install dependencies
npm install

# Run frontend & backend dev servers
npm run dev
```
